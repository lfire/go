# 导学 · 建立地图

> 这一阶段不写复杂代码，只做三件事：看清整张学习地图、把环境真正跑通、把第一个程序的每一行都弄明白。很多人学 Go 卡在后面，不是因为语法难，而是因为第一行代码就只是照抄。我们从一开始就养成「每行都问为什么」的习惯。

建议按顺序做完，别跳。环境相关的报错在这个阶段解决掉，后面 100 多讲才不会反复被打断。

## 建议的学习节奏

- **零基础**：按讲次顺序走，每讲的代码亲手敲一遍，做完动手练习再往下。
- **有其他语言经验**：可以快速掠过阶段一，但从「阶段二 · 切片 / 接口」开始别跳，Go 的差异集中在这里。
- **已经在写 Go**：直接从阶段三（核心机制）或阶段五（工程化）切入，用阶段前测判断哪里需要补。
- **想做项目**：去[工程实战](/projects/)挑一个 ★ 或 ★★ 的场景先跑通，再回头补原理。
