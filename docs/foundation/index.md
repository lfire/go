# 阶段一 · 编程地基

> 零基础最容易缺的不是语法，而是「程序在干什么」的模型。这一阶段把值、类型、内存、函数、包这些地基补齐，并且刻意用其它语言的习惯做对照 —— 知道差别在哪，才不会把别的语言写法硬套到 Go 上。

## 怎么学这一阶段

每讲的代码都亲手敲一遍。特别是「栈、堆、值语义与指针」，后面 interface、逃逸分析、GC 全靠这一讲的直觉。

<Callout type="warn" title="最容易踩的坑" text="Go 没有隐式类型转换。int 与 int64、string 与 []byte 之间都要显式写清楚，这不是啰嗦，是让代价可见。" />
